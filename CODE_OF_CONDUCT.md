# Code of conduct

Be respectful, constructive, and patient. Discuss code and evidence, not people.
Harassment, discrimination, threats, doxxing, publication of private network
data, and deliberate unsafe hardware instructions are not accepted.

Maintainers may edit, hide, or remove content and restrict participation when
needed to protect contributors or users. Report conduct concerns privately to
the repository owner. Report security problems through `SECURITY.md`, never a
public issue.
