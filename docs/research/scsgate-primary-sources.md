# Primary sources

- Firmware source, target endpoint implementation: [papergion/ESPscsgate_32_C3](https://github.com/papergion/ESPscsgate_32_C3/blob/master/ESPscsgate_32_C3.ino), consulted 2026-08-02.
- Official firmware manual: [ESPscsgate_32_C3.pdf](https://github.com/papergion/ESPscsgate_32_C3/blob/master/ESPscsgate_32_C3.pdf), by Guido Pagani, consulted 2026-08-02.

Implementation targets firmware `VER_7.004`. These firmware-controlled HTML endpoints are presentation-oriented, so parsers deliberately treat absent or unrecognized values as unknown.

`appunti_scs.pdf` is a local, non-redistributed research source. Its alarm,
thermostat, and intercom mappings are hypotheses and are not implementation
authority.
